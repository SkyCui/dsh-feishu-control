# Third-party notices

This package bundles the official Feishu/Lark Node.js SDK and its transitive
runtime dependencies so that DeepSeek Harness can install the plugin without
running third-party lifecycle scripts.

The exact package versions, declared licenses, and complete license texts for
the bundled build are generated at `lib/THIRD_PARTY_LICENSES.txt`. That file is
included in every npm tarball.

The project itself is licensed under the MIT License in [LICENSE](./LICENSE).
